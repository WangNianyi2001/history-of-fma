# 未来媒体协会史

本项目记录中国传媒大学未来媒体协会的变迁、人物、故事。

- [在线阅读](https://github.com/WangNianyi2001/history-of-fma/blob/master/build/main.pdf)
- [下载链接](https://raw.githubusercontent.com/WangNianyi2001/history-of-fma/master/build/main.pdf)

## 如何贡献

在本地安装 XeLaTeX 和 CTeX，编辑 `src/` 下的源码，在根目录执行 `make build` 即可。

)。
